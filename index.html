      Browse the LINZ Data Service

      Find a dataset on the left, then filter it with the query builder. Field names and types come straight from LINZ, so you pick them from lists instead of typing them.

      1. Add your API key (top right). It's stored only in this browser and sent only to data.linz.govt.nz.
      2. Search for a vector layer or table and open it.
      3. Build a query, run it, and view the results as a table and on a map.
      4. Star the datasets you use often. Your last query on each one is remembered too.

      Look up an address

      Search for an address with the box on the map. To see the nearest address, the parcel and the title at any spot, right-click it (long-press on a touch screen) or switch on What's here? and click.
